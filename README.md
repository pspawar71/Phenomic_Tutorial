# RStudio RGB-to-Plot GLI Workflow

This package is designed for RStudio. Open `RGB_GLI_Plot_Traits.Rmd` and run chunks sequentially. No raster or overlay visualization is interactive.

Required data:

```text
data/rgb_orthomosaic.tif
data/plot_boundaries.geojson
```

Install packages with `install.R`.

## Launch in Binder RStudio

Use this link after uploading the repository to GitHub:

```text
https://mybinder.org/v2/gh/pspawar71/remote-sensing-htp-binder/main?urlpath=rstudio
```

Students should open `RGB_GLI_Plot_Traits.Rmd` and run chunks from top to bottom. Binder sessions are temporary, so download the CSV in `outputs/` before closing the session.
